# StarAberrationDiagnostics

Diagnostics of the optical system from the shapes of the stars: sensor tilt,
corrector spacing, field curvature, coma, collimation and tracking errors,
with maps and an assessment with suggested corrections.

- `StarAberrationDiagnostics.js` - the PixInsight script (signed releases are
  published through the update repository at
  <https://tricx.de/pi-scripts/StarAberrationDiagnostics/>).
- `python/` - a port to Python with a Qt GUI (work in progress).
- The handbook, the dialog reference and the examples are published on
  <https://tricx.de/pi-scripts/StarAberrationDiagnostics/>; `CLAUDE.md`
  describes how their sources are organized.
